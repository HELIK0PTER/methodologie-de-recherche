# Sommelier Virtuel : Présentation de Recherche Appliquée

Ce projet est une application de présentation interactive réalisée avec **React**, **Tailwind CSS** et **Framer Motion**. Elle expose la méthodologie de recherche pour l'implémentation d'un sommelier virtuel intelligent sur une plateforme e-commerce de vin.

---

## 🛠️ Installation & Développement

1. **Installation** :

   ```bash
   npm install
   ```

2. **Lancer le serveur de dev** :

   ```bash
   npm run dev
   ```

3. **Navigation** :
   - Utilisez les **flèches** ou **espace** pour panner les sections.
   - Accédez au widget de chat en bas à droite pour la démonstration en direct.
